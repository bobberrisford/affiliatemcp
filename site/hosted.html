why hosted

the work stops depending on you being at the desk.

Nothing to install. No Node.js, no terminal, no config file. You sign in with an email link and connect a network in a guided form. If you have ever been blocked from installing software on a work laptop, this is the version for you.

It runs with the lid shut. Scheduled checks and digests happen on our infrastructure, so the Monday brief exists before you open the laptop and a Saturday reversal spike is caught on Saturday.

Everything else is identical to the free local server — the same open-source adapters, the same operations, the same answers. Hosted removes two constraints; it does not add capability you cannot have for free.

your keys

you can take it all back in one click.

  • →Claude never receives your network keys. They go into the encrypted dashboard and nowhere else. Your AI client gets a short-lived, scoped session instead — there is no token to paste anywhere, in either direction.
  • →Encrypted per account, decrypted only at call time. Each account has its own key, used in memory for the moment a request runs, never written back in plaintext.

the questions people actually ask
do I need to be technical?

No. Sign in with an email link, pick a network, paste the API key it asks for — the form tells you where to find it in that network's own dashboard — and add one URL to Claude. There is nothing to install and no terminal.

which networks work on hosted?

Awin, CJ Affiliate, Impact, and Rakuten Advertising. Those are the four whose terms have been checked and whose adapters are mature enough to run unattended.

The free local server covers dozens more. Holding someone's API key is a heavier commitment than helping them use their own, and we would rather draw that line visibly than blur it to make this page look better.

what counts as a "report"?

One 30-minute working session, not one question. Your first request opens the window and everything you ask inside it is included. Three of those a week on the free plan, on a rolling seven days.

what happens if I cancel?

You drop back to the free plan rather than losing access. Cancel from the billing portal in your dashboard, any time. If you delete the account instead, everything stored with it goes too.

is the local server still free?

Yes, and it always will be. It is MIT licensed, open source, and does everything hosted does for every supported network, with your keys never leaving your machine. If you can run it yourself, run it yourself — hosted exists for the people who cannot, and for work that has to happen while the laptop is shut.

the honest bits

  • →Four networks hosted today. Awin, CJ Affiliate, Impact, and Rakuten Advertising. Others stay local-only until their terms are checked — the free local server covers all of them.
  • →One long-lived token per network. These four networks only issue full-access API tokens, not scoped read-only ones. Generate one dedicated to this connection, and revoke it in the network's dashboard if you ever disconnect.
  • →Export and hard delete both work today. GET /account/export returns everything we hold about you as one JSON document, credential values excluded. Neither has a dashboard button yet; both are authenticated API requests.
  • →No SOC 2, no ISO 27001, no DPA on offer. If your procurement needs those, use the local server — same capability, no vendor relationship.
  • →Local stays free and complete. Hosted removes the install and the laptop-awake constraint; it does not gate anything the open-source server already does.
